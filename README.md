# mockmuse-web 🦞

HTML starter site for mock.muse.

This is the starter version of the site. The full personal website lives at **https://mockmuse.github.io** — see the [mockmuse.github.io](https://github.com/mockmuse/mockmuse.github.io) repo.

## Run locally

```bash
# From this folder, serve the files with any static server, for example:
python3 -m http.server 8000
# Then open http://127.0.0.1:8000 in your browser.
```

Or just open `index.html` directly in a browser.
